## Features

<CardGrid stagger>
  <Card title="React templates" icon="seti:react">
    Write the image as a component with inline styles. Async components can
    load content entries, images and remote data.
  </Card>
  <Card title="Static or on demand" icon="rocket">
    Prerender with `getStaticPaths`, or set `prerender = false` behind any
    Astro adapter. Vercel needs no extra configuration.
  </Card>
  <Card title="Fonts and scripts" icon="document">
    Register your own fonts. Thai, Japanese, Korean and Arabic fall back to
    Noto Sans automatically.
  </Card>
  <Card title="Emoji" icon="star">
    Twemoji, Noto, OpenMoji, Fluent or your own font's glyphs.
  </Card>
  <Card title="Debug in the browser" icon="magnifier">
    Swap `.png` for `.debug` to see the template as a live HTML page.
  </Card>
  <Card title="WebAssembly renderer" icon="setting">
    Takumi runs on WASM everywhere, so there is no native binary to ship.
  </Card>
</CardGrid>
